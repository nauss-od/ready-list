\# Creative Graphic Web Design Instructions



Act as a senior product designer, creative art director, and frontend engineer.



The required design level is not ordinary.

Do not produce a basic dashboard.

Do not produce a generic government website.

Do not produce flat, lifeless admin screens.



Design standard:

Create a modern Saudi Vision 2030 style digital experience.

The interface must feel premium, institutional, graphic, elegant, and contemporary.

The design must look like a high-end national platform, not a simple internal system.



Visual direction:

Use strong graphic composition.

Use layered sections.

Use elegant geometric patterns.

Use subtle depth.

Use refined gradients.

Use large confident headings.

Use clear content blocks.

Use polished cards.

Use premium spacing.

Use professional icons.

Use refined micro-interactions.

Use clean motion only where useful.

Use visual storytelling across the page.



Reference feeling:

Inspired by modern Saudi institutional websites such as national centers, semi-government platforms, and Vision 2030 digital products.

The design should feel official, ambitious, clean, modern, and visually memorable.



Avoid:

basic dashboard layout

plain white pages

weak typography

random colors

oversized cards

crowded sections

template-like admin design

cheap gradients

unbalanced spacing

generic Tailwind components

repetitive cards

visual noise

unnecessary animations

changing the system logic



Focus on:

visual hierarchy

creative layout

graphic identity

section rhythm

premium typography

balanced whitespace

elegant cards

clean tables

beautiful forms

precise buttons

clear navigation

empty states

alerts and badges

responsive behavior

mobile quality

dashboard polish

landing page quality

institutional visual confidence



Technical rules:

Do not rebuild the project from scratch.

Do not change business logic.

Do not change routes.

Do not remove features.

Do not change authentication.

Do not change database logic.

Do not break existing workflows.

Keep the code clean and production-ready.

Keep the project compatible with React, Next.js, Tailwind, and Vercel.



Design process:

First review the current interface.

Identify why it looks ordinary.

Then improve the visual system across layout, spacing, typography, cards, forms, tables, navigation, and responsive behavior.

After implementation, critique the result as a strict design director.

Fix weak visuals before finishing.



Final quality target:

The website must look like a polished strategic digital platform suitable for executive presentation, national programs, and high-profile institutional use.
